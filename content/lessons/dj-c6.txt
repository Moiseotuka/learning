## Introduction aux bases de données Django avancées

Dans ce chapitre final, nous explorons les concepts avancés de la persistance des données dans Django, en nous concentrant sur les performances, la fiabilité et les bonnes pratiques de déploiement.

### Optimisation des performances ORM

#### Sélection efficace des données

Utilisez toujours `select_related()` et `prefetch_related()` pour optimiser les requêtes :

```python
# select_related pour les relations ForeignKey (jointure SQL)
articles = Article.objects.select_related('auteur', 'categorie').all()

# prefetch_related pour les relations ManyToMany ou ForeignKey inverses
articles = Article.objects.prefetch_related('tags', 'commentaires').all()
```

#### Indexation de base de données

Ajoutez des index sur les champs fréquemment interrogés dans votre modèle :

```python
from django.db import models

class Article(models.Model):
    titre = models.CharField(max_length=200, db_index=True)
    date_publication = models.DateTimeField(db_index=True)
    contenu = models.TextField()
    
    class Meta:
        indexes = [
            models.Index(fields=['-date_publication']),
        ]
```

### Transactions et intégrité des données

#### Gestion des transactions

Utilisez `transaction.atomic()` pour garantir l'intégrité des opérations multiples :

```python
from django.db import transaction

def creer_article_avec_commentaire(titre, contenu, auteur):
    with transaction.atomic():
        article = Article.objects.create(titre=titre, contenu=contenu, auteur=auteur)
        Commentaire.objects.create(article=article, texte="Commentaire par défaut")
    return article
```

#### Points de sauvegarde

Les transactions Django utilisent par défaut le backend de base de données actuel. Vous pouvez personnaliser le comportement avec les décorateurs `@transaction.atomic`.

### Sérialisation et API

#### Sérialisation avec Django REST Framework

Pour créer des API, utilisez Django REST Framework :

```python
from rest_framework import serializers, viewsets
from .models import Article

class ArticleSerializer(serializers.ModelSerializer):
    class Meta:
        model = Article
        fields = ['id', 'titre', 'contenu', 'date_publication', 'auteur']

class ArticleViewSet(viewsets.ModelViewSet):
    queryset = Article.objects.all()
    serializer_class = ArticleSerializer
```

#### Personnalisation du sérialisation

Vous pouvez ajouter des méthodes personnalisées dans vos sérialiseurs :

```python
class ArticleSerializer(serializers.ModelSerializer):
    auteur_nom = serializers.CharField(source='auteur.nom', read_only=True)
    commentaires_count = serializers.IntegerField(read_only=True)
    
    class Meta:
        model = Article
        fields = ['id', 'titre', 'auteur_nom', 'commentaires_count']
    
    def get_commentaires_count(self, obj):
        return obj.commentaires.count()
```

### Tests unitaires pour les modèles

#### Écriture de tests

Django inclut un framework de tests intégré :

```python
from django.test import TestCase
from .models import Article

class ArticleModelTest(TestCase):
    def test_creation_article(self):
        article = Article.objects.create(titre="Test", contenu="Contenu de test")
        self.assertEqual(article.titre, "Test")
        self.assertEqual(article.contenu, "Contenu de test")
    
    def test_str_representation(self):
        article = Article.objects.create(titre="Test Article")
        self.assert str__(article) == "Test Article"
```

#### Tests de base de données

Utilisez les fixtures et les factories pour des tests reproductibles :

```python
import factory
from django.db import models

class ArticleFactory(factory.django.model_factory_factory(Article)):
    titre = factory.Sequence(lambda n: f"Article {n}")
    contenu = "Contenu par défaut"
```

### Déploiement et maintenance

#### Configuration de production

Pour le déploiement en production :

1. Utilisez Gunicorn ou uWSGI comme serveur WSGI
2. Configurez NGINX ou Apache comme proxy inverse
3. Utilisez des variables d'environnement pour les paramètres sensibles
4. Activez le mode debug uniquement en développement

```bash
# Exemple de configuration Gunicorn
gunicorn mon_projet.wsgi:application --bind 0.0.0.0:8000
```

#### Sauvegardes et récupération

Planifiez des sauvegardes régulières de votre base de données :

```bash
# Sauvegarde PostgreSQL
pg_dump ma_base_de_donnees > backup_$(date +%Y%m%d).sql

# Sauvegarde MySQL
mysqldump -u utilisateur -p ma_base_de_donnees > backup_$(date +%Y%m%d).sql
```

### Sécurité finale

#### Headers de sécurité

Ajoutez ces headers dans vos paramètres de production :

```python
# settings.py
SECURE_BROWSER_XSS_FILTER = True

SECURE_HSTS_INCLUDE_SUBDOMAINS = True
SECURE_HSTS_SECONDS = 31536000
SECURE_SSL_REDIRECT = True

```
